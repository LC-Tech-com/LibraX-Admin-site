# LibraX – Smart Library Management System

LibraX is a smart library management system designed to automate book borrowing and returning using face recognition and barcode-based book identification.

## Features

- User registration and management
- Face recognition-based user verification
- Book borrowing and return management
- Barcode-based book identification
- Admin dashboard
- MySQL database integration
- REST API for application communication
- User and library record management

## Technologies Used

- Python
- Flask
- MySQL
- SQLAlchemy
- InsightFace
- OpenCV
- HTML
- CSS
- JavaScript
